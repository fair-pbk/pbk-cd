# Validation

This folder contains scripts, model implementations, scenarios, and outputs used to validate the cadmium PBK model.

## Reference implementations

- **R** (`R/`): R versions of the Gastellu 2026 model and its revised implementation, with scripts for single-dose, repeated-dose, Pouillot, and lifetime validation runs.
- **mrgsolve** (`mrgsolve/`): The mrgsolve C++ implementation with scripts for single-dose, repeated-dose, and lifetime repeated-dose validation runs.

The `reference_scenarios.yaml` file lists the R and mrgsolve reference scripts and maps each script to the output file it generates.

## Scenarios

- **`R.yaml`**: Defines oral single-dose, repeated-dose, and lifetime scenarios for comparison with the R reference implementations.
- **`mrgsolve.yaml`**: Defines the corresponding oral single-dose, repeated-dose, and lifetime scenarios for comparison with mrgsolve.
- **`lifetime_comparison.yaml`**: Compares lifetime and non-lifetime model variants under constant and body-weight-adjusted repeated dosing.

## Running simulations

From the repository root, run all validation simulations with:

```text
python ./scripts/run_validation.py
```

Existing results are reused by default. Add `-f` to force recomputation, `--skip_r` to skip the R reference scenarios, or `-c` followed by one or more YAML files to run selected scenario configurations.

## Outputs

The `outputs/` folder is generated by the validation scripts. It contains R and mrgsolve reference results, scenario comparison results, plots, and lifetime comparison results. Existing output files may be reused on subsequent runs unless recomputation is forced with `-f`.
