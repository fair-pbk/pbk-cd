# Validation

This folder contains scripts, model implementations, scenarios, and outputs used to validate the cadmium PBK model.

## Reference implementations

R versions of the Gastellu 2026 model and its revised implementation, with scripts for single-dose, repeated-dose, Pouillot, and lifetime validation runs.

## Scenarios

Each YAML file in `scenarios/` defines a separate validation scenario:

- `scenarios/oral_single.yaml`
- `scenarios/oral_repeated.yaml`
- `scenarios/oral_repeated_lifetime.yaml`
- `scenarios/oral_repeated_pouillot.yaml`

These scenarios compare the SBML model with the original and revised R reference implementations. All individuals are male (`sex = 1`); `BW` denotes the model-calculated body weight.

| Scenario | Duration | Dosing | Individual |
|---|---:|---|---|
| `oral_single` | 40 days | Single oral bolus of 1000 ug at day 0 | Age 30 years; no BW adjustment |
| `oral_repeated` | 40 days | Oral bolus of 100 ug every day from day 0 | Age 30 years; no BW adjustment |
| `oral_repeated_lifetime` | 10 years (3650 days) | Oral bolus of 10 ug/kg BW every day from day 0 | Age 0 years; daily BW-adjusted dose |
| `oral_repeated_pouillot` | 80 years (29200 days) | Oral bolus of 0.2 ug/kg BW every day from day 0 through day 18250 | Age 0 years; daily BW-adjusted dose |

## Running simulations

From the repository root, run all validation simulations with:

```text
python ./scripts/run_validation.py
```

Existing results are reused by default. Add `-f` to force recomputation, `--skip_r` to skip the R reference simulations, or `-c` followed by one or more scenario YAML files to run selected configurations. For example:

```text
python ./scripts/run_validation.py -c validation/scenarios/oral_single.yaml
```

## Outputs

The `outputs/` folder is generated by the validation scripts. It contains R reference results, scenario comparison results, plots, and lifetime comparison results. Existing output files may be reused on subsequent runs unless recomputation is forced with `-f`.
